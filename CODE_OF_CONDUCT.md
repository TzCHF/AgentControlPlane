# Code of Conduct

AgentControlPlane contributors communicate with technical clarity and respect.
Repository conversations should help participants reproduce behavior, evaluate
evidence, and improve the project.

## Expected conduct

- Discuss code, designs, test evidence, and documented behavior.
- Give specific feedback with file, command, or runtime context.
- Respect different experience levels, languages, identities, and viewpoints.
- Credit contributors for their work and sources.
- Remove credentials, personal data, and private workspace details from public
  reports.

## Unacceptable conduct

- Harassment, threats, discriminatory language, or personal attacks.
- Publishing another person's private information.
- Sexualized language or unwanted sexual attention.
- Repeated disruption of issues, reviews, or discussions.
- Sharing credentials, exploit details, or private logs in public threads.

## Enforcement

Maintainers may edit, hide, lock, or remove content that violates this policy.
They may limit repository participation when behavior continues or creates a
safety risk.

Report conduct concerns privately to the repository owner using the private
reporting route described in [SECURITY.md](SECURITY.md). Include relevant links,
dates, and screenshots. The maintainer will review the report and communicate
the action taken when a response channel is available.
