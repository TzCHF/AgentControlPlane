# AgentControlPlane v0.9.0

This release packages the web-AI-to-local-executor workflow for public testing.

## Included

- Native cross-executor continuation with a stable logical task id,
  append-only executor history, and compact evidence packages.
- A confirmed live MCP demo that creates and verifies `hello.txt` through a
  selected local executor.
- Bilingual repository onboarding, contribution guidance, issue forms, and a
  reproducible Social Preview source.
- Deterministic Windows source and browser companion ZIP files.
- SHA256 manifest generation for explicit release assets.
- A 90-second video walkthrough of the verified OpenCode demo result.

## Operating limits

- The supported deployment is a local, single-user control plane bound to
  loopback.
- Every executor uses its configured account, subscription, API key, and model
  quota.
- Automatic reroute is disabled by default and accepts infrastructure failures
  only when the operator enables the policy.
- Codex on Windows requires its sandbox setup. OpenCode and Claude Code run with
  the permissions of the local user account.
- ChatGPT custom MCP app availability depends on the selected ChatGPT plan and
  workspace policy.
